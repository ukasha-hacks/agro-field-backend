# DM Sans for local reports

The regular and bold TrueType fonts are bundled so PDF generation works without a font download. They also provide the chart labels in Matplotlib. ReportLab embeds subsets in the PDF.

Source: Google Fonts, DM Sans, https://github.com/google/fonts/tree/main/ofl/dmsans

The static instances use weight 400 or 700 and optical size 14 from the original variable font. FontTools produced these instances without changing the outlines. Names identify the regular and bold styles. The accompanying SIL Open Font License applies; retain OFL.txt when redistributing.

These are design assets, not agricultural data.
